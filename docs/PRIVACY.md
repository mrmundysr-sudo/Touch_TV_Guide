# Touch TV Guide — Privacy Policy (draft for the store listing)

_Last updated: 2026-11-05. Host this text at a public URL before a Play listing._

**Touch TV Guide** is a free TV listings and reminders app. It has no account system, no ads, no analytics and no tracking.

**What stays on your device:** the zip code you enter, the market and provider you choose, channel numbers/categories/favorites you set, your reminders, and a saved copy of the public TV guide. Nothing is uploaded.

**Location (optional):** if you tap "Use my approximate location" and allow it, the app reads your phone's last known approximate location once to suggest a zip code. It is not stored, not sent anywhere, and the app works fully if you decline and type a zip instead.

**Network use:** the only network request is downloading the public guide file from EPGTalk (`raw.githubusercontent.com` by default, or the address you set in Settings), at most once a day. That server can see your IP address and standard request headers, as any web server does. Channel logos (if the guide includes them) are fetched from the image address in the guide.

**Notifications:** used only for reminders you set.

**Children:** the app collects no personal information from anyone.

**Data sources:** listings © their respective providers, via EPGTalk (epgtalk.com). Zip code positions derive from US Census Bureau data.
