# Touch TV Guide

A free TV guide companion for Android: local listings, favorites, search and show reminders. It does not play TV.

- **Listings:** [EPGTalk](https://epgtalk.com) US Local guide (about 72 hours, ~140 markets), downloaded at most once a day and cached on the device.
- **Offline:** everything is stored in an on-device database; the guide works without a connection.
- **Private:** no account, no ads, no tracking. See `docs/PRIVACY.md`.

## Layout
| Path | What |
|---|---|
| `core/` | Pure-JVM Kotlin: XMLTV parser, guide rules (`GuideLogic`), market/zip rules, reminder + refresh rules. Shared contract for iOS (`docs/DATA_MODEL.md`). |
| `app/` | Android app (Jetpack Compose, Room, WorkManager, OkHttp). |
| `app/src/main/assets/` | `markets.csv`, `zips.csv` (generated by `tools/build_market_data.py`). |
| `docs/` | Decisions, plan, data model, privacy text, build log. |

## Build and test
Requires JDK 17+ and the Android SDK (`ANDROID_HOME`, platform 35).

```bash
./gradlew :core:test                # pure JVM rules + parser
./gradlew :app:testDebugUnitTest    # Robolectric: Room, refresh, setup, reminders
./gradlew :app:assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
```
CI (`.github/workflows/android.yml`) runs all three on pushes to `claude/android` and uploads the debug APK as the `touch-tv-guide-debug-apk` artifact.
